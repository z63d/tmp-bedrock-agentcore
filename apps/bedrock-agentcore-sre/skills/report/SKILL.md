# レポート作成

調査結果を以下のフォーマットでまとめること。

## フォーマット

```
# インシデントレポート

## 概要
- 発生日時:
- 影響範囲:
- 重要度: Critical / High / Medium / Low

## 事象
何が起きたかを簡潔に記述。

## 原因
根本原因の分析結果。

## 対応
実施した、または推奨する対応。

## 再発防止策
今後同様の問題を防ぐための施策。
```

## ルール

- 調査で判明した事実のみ記載する。推測は「推測:」と明記する
- タイムスタンプは JST で記載する
- 影響を受けたリソース名は正確に記載する
